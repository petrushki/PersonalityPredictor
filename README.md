# PersonalityPredictor

## Description of the project:
This project is for the Midterm project assignment part of the ML-Zoomcamp course from DataTalks (link to the course).
The project aims to predict weather a personality is more leaning towards an extroverted one or a inrtroverted one based on 7 features. The features are: 'time_spent_alone', 'stage_fear', 'social_event_attendance',
       'going_outside', 'drained_after_socializing', 'friends_circle_size',
       'post_frequency'

The target variable is a boolean named 'personality' and it's 1 when the personality is Introverted and 0 for Extroverted. 
The project could be used for personality prediction and behavioral modeling. Possible use cases could be: 
- personality modeling
- audience segmentation and marketing
psychology and behavioral research

Dataset:

link to download: https://huggingface.co/datasets/syncora/introvert_extrovert_personality_dataset

This synthetic personality dataset includes 10,000 high-fidelity records simulating behavioral and social patterns of introverts and extroverts. Built using **Syncora.ai**’s advanced data generator, it mirrors real-world distributions while ensuring zero privacy risk. 

Introversion and extroversion influence how people socialize, recharge, and respond to stimuli. This dataset captures behaviors such as:

    Time spent alone
    Frequency of social events
    Social media posting habits
    Energy drain after socializing
